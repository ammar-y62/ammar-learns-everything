# 💸 Smart Budget Tracker

A simple and intuitive budget tracking app built with **React** and **Express**, designed to help users manage expenses, track categories, and gain insights into their spending habits. Bonus: integrates AI to suggest budget optimizations based on trends.

---

## 🔧 Features

- ✅ Add, edit, and delete income and expenses
- 📊 Track total balance, spending breakdown by category
- 📅 Filter transactions by date range
- 📈 Visualize spending trends with charts
- 🧠 **[Bonus]** AI Suggestions:
  - "You're spending 22% more on food this month"
  - "Consider capping entertainment at \$80"

---

## 🧰 Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express
- **State Management**: useReducer + Context API
- **Testing**: Jest, React Testing Library
- **AI**: OpenAI API (optional bonus)
